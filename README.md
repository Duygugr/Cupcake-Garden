# 🧁 Cupcake Garden

Cupcake Garden, modern ve kullanıcı dostu bir cupcake e-ticaret web sitesi projesidir.  
Kullanıcıların ürünleri inceleyebildiği, sepete ekleyebildiği ve sepet işlemlerini yönetebildiği responsive bir frontend uygulamasıdır.

## 🚀 Özellikler

- 🧁 Ürün listeleme
- 🛒 Sepete ürün ekleme
- ➕ Ürün adet artırma
- ➖ Ürün adet azaltma
- 🗑️ Sepetten ürün silme
- 💾 LocalStorage ile sepet verilerini saklama
- 📦 Sipariş onay ekranı
- 📱 Responsive tasarım
- 🎨 Modern kullanıcı arayüzü

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Font Awesome
- LocalStorage

![Cupcake Garden](./images/cupcake-website%201.png)

Proje içerisinde modern tasarım, ürün kartları ve kullanıcı deneyimini geliştiren dinamik sepet işlemleri uygulanmıştır.
